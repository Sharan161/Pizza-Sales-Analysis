#  Pizza Sales Analysis Dashboard

##  Project Overview

The **Pizza Sales Analysis** project is an interactive Power BI dashboard designed to analyze pizza sales performance.

The dashboard provides insights into total sales amount, quantity sold, average pizza price, monthly sales trends, pizza categories, sizes, and tax amounts.

The main objective is to understand sales patterns and identify important business insights through data visualization.

##  Project Objectives

- Analyze total pizza sales amount.
- Understand the total quantity of pizzas sold.
- Analyze the average pizza price.
- Identify popular pizzas based on quantity sold.
- Compare sales across different pizza categories.
- Analyze sales trends over months.
- Understand sales distribution by pizza size.
- Analyze tax amounts across pizza categories.

##  Dashboard KPIs

The dashboard includes the following key performance indicators:

1. **Total Amount** – Displays the total sales amount.
2. **Total Quantity Sold** – Shows the total number of pizzas sold.
3. **Average Price** – Displays the average pizza price.
4. **Sales Amount** – Used to analyze sales performance over time.

##  Visualizations

The dashboard contains the following visualizations:

### 1. Quantity Sold by Pizza Name
- Clustered bar chart.
- Identifies pizza names based on quantity sold.

### 2. Monthly Sales Amount Trend
- Area chart.
- Displays monthly sales amount trends.

### 3. Quantity by Category and Size
- Column chart.
- Compares pizza quantities across categories and sizes.

### 4. Monthly Sales by Category
- Line chart.
- Compares monthly sales amounts across pizza categories.

### 5. Average Price by Pizza Size
- Clustered column chart.
- Compares average pizza prices by size.

### 6. Sales Amount by Pizza Size
- Pie chart.
- Displays the sales amount distribution across pizza sizes.

### 7. Tax Amount by Category
- Clustered bar chart.
- Compares tax amounts across pizza categories.
